## Anuncio 1: presupuesto y WhatsApp

**Título:** Calculadora de presupuestos a medida para tu negocio  
**Precio mostrado:** 149 € (ориентир для базовой версии, цена уточняется по ТЗ)

**Descripción:**

¿Te escriben para preguntar precios y acabas pidiendo siempre los mismos datos?

Te puedo hacer una página sencilla para que el cliente elija lo que necesita, vea un importe aproximado y prepare un mensaje con todo para compartirlo por WhatsApp.

Por ejemplo, para negocios de reformas, limpieza, eventos o servicios a domicilio.

Trabajo online. El precio depende de las opciones y de cómo se calculan; el anuncio es para una versión básica.

Tengo una demo funcionando que puedo enseñar dentro del chat. Si me cuentas tu caso, te digo si merece la pena hacerlo y cuánto costaría.

No es un bot que mande mensajes automáticamente. El cliente decide cuándo compartir el presupuesto.

## Anuncio 2: tareas en Python

**Título:** Automatizo tareas repetitivas con Python  
**Precio mostrado:** 89 € (только простая задача, цену утверждать после входных примеров)

**Descripción:**

¿Pierdes tiempo copiando datos, ordenando archivos o pasando información de una hoja a otra?

Puedo prepararte un script pequeño en Python para quitarte ese trabajo manual. Por ejemplo: limpiar un CSV, unir varias hojas o transformar datos a un formato que uses cada día.

Trabajo en remoto. Primero vemos un ejemplo de los archivos y acordamos exactamente qué tiene que hacer.

El precio del anuncio es orientativo para una tarea sencilla. Si me explicas qué haces ahora a mano, te digo si se puede automatizar.
