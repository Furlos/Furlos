## FAQ

**¿Los mensajes se envían solos?** No. La página abre WhatsApp con un texto preparado y el cliente decide si lo envía. La API empresarial sería otro proyecto.

**¿Puedo cambiar precios?** Sí, te entrego el código donde se modifican. Un panel de administración se presupuesta aparte.

**¿Incluye hosting?** No. Entrego archivos e indicaciones básicas. Si necesitas despliegue, lo acordamos antes.

**¿Se adapta a mi negocio?** Si el precio se puede calcular mediante reglas relativamente sencillas, sí. Para servicios que requieren visita técnica el precio se marca como estimado.

**¿Puedo añadir funciones?** Sí, primero definimos alcance, plazo y coste aparte.
