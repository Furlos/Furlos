## The actual service

Build a small, mobile-friendly web quote calculator for Spanish-speaking businesses. Customers select services, see an indicative price, then tap **Compartir por WhatsApp** to open WhatsApp with the estimate ready to send. **No messages are sent automatically, no WhatsApp Business API is included.** The existing sample is a proof of concept with invented event prices, not a customer case study.

Indicative direct price for a basic scoped project: **from €149**, final scope/price confirmed individually. No promise of hosting, domain, CRM, payments, or ongoing support in that base price.
